# TojScript v1.0.14

Забони барномасозӣ ба забони тоҷикӣ!

## Насб кардан (Установка)
```
pip install dist/tojscript-1.0.14-py3-none-any.whl --force-reinstall
```

## Истифода (Использование)
```
toj main.py
```

## Мисолҳо (Примеры)
```
toj мисолҳо/салом.py
toj мисолҳо/графика.py
toj мисолҳо/рангинкамон.py
```

## Калимаҳои калидӣ (Ключевые слова)
| TojScript | Python |
|-----------|--------|
| оғоз(){} | main block |
| чоп() | print() |
| ворид() | input() |
| агар | if |
| дигар | else |
| барои м (1..10){} | for m in range(1,11) |
| функсия ном(а,б){} | def ном(а,б): |
| баргардон | return |
| дар_ҳолати(){} | while |
| тоқ() | odd filter |
| ҷуфт() | even filter |
| экран() | window |
| ранг() | rectangle |
| доира() | circle |
| хат() | line |
| матн() | text |
| нишон() | show window |
